Up and running in 30 seconds

Create a client, ask typed questions about your state, and read the answers — all with compile-time type safety.

  • ✓ Client reads TYPESAFE_API_KEY from the environment
  • ✓ Questions validate before any network I/O
  • ✓ Answers are statically typed by question kind
  • ✓ Retries, timeouts, and headers are handled for you
  • ✓ Responses include usage stats and raw HTTP access
// Create a client (reads TYPESAFE_API_KEY)
client, err := typesafe.NewClient()
if err != nil { return err }
defer client.Close()

// Ask typed questions about a state
resp, err := client.SystemOne(ctx, &typesafe.SystemOneParams{
    State: map[string]any{
        "document": "I was charged twice.",
    },
    Questions: typesafe.Questions{
        "category": typesafe.Choice{
            Instructions: "What is this about?",
            Criteria: typesafe.ChoiceCriteria{
                "billing": nil,
                "technical": nil,
            },
        },
        "urgent": typesafe.Noul{
            Instructions: "Is this urgent?",
        },
    },
})

// Read statically-typed answers
resp.Choices()["category"].Choice    // "billing"
resp.Nouls()["urgent"].Noul         // 0.92

Three primitives, typed answers

The question kind you ask determines the statically-known answer type you get back.

Primitive Ask about Answer type Key field
Noul Yes/no probability NoulAnswer Noul float64 — probability 0..1
Choice Classification ChoiceAnswer Choice string + Confidence + Probabilities
Score Rubric scoring ScoreAnswer Score float64 + Legend + Probabilities

Plus RawQuestion for passthrough — any shape the API supports, validated server-side.

Structured error taxonomy

Every failure matches with errors.As. Subclasses embed *APIError.

*TypeSafeError

Shared root of every SDK error. Used directly for client-side failures (missing key, bad params).

*APIError

Any non-2xx response. Carries Status, Body, DecodedBody, Headers, RequestID.

*BadRequestError … *RateLimitError

Status-specific subclasses for 400, 401, 403, 404, 422, 429.

*InternalServerError

Any status ≥ 500. Retried by default policy.

*ConnectionError

No HTTP response. Transport cause preserved via Unwrap.

*TimeoutError

Attempt exceeded timeout. Satisfies net.Error and *ConnectionError.

var rl *typesafe.RateLimitError
if errors.As(err, &rl) && rl.RetryAfterMs != nil {
    fmt.Println("retry after ms:", *rl.RetryAfterMs)
}
