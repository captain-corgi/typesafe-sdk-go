# Walkthrough data (`data/<leaf>.js`)

Per-example data for the **Step-through** tab of the example browser in
[`../index.html`](../index.html). Hand-maintained — this is *not* generated by
`tools/pagegen` and is unrelated to the generated `examples.json`.

## Naming rule

The file name is the leaf directory of the example it walks through:

```
data/01-semantic-command-switch.js  ↔  examples/go-software-use-cases/01-semantic-command-switch
```

The page derives it from the catalog-relative id: `ex.id.substring(ex.id.lastIndexOf('/') + 1)`.

## Data shape

Each file is a plain script assigning one object into a global (no `fetch`, so
it works from `file://` and on the Pages subpath):

```js
window.__TYPESAFE_FLOWS__ = window.__TYPESAFE_FLOWS__ || {};
window.__TYPESAFE_FLOWS__["<leaf>"] = {
  id: "<leaf>",              // same as the file name
  catalog: "<catalog-id>",   // matches examples/ top-level dir
  title: "…",                // walkthrough title
  tagline: "…",              // one-line summary
  concepts: ["…"],           // keywords (informational)
  source: "https://github.com/…/examples/<catalog>/<leaf>/main.go",
  run: "go run ./examples/<catalog>/<leaf>",
  steps: [
    { id: "s1", title: "…", kind: "setup", file: "main.go",
      lines: "22-24", detail: "…", code: "\t…" },
    // …
  ],
  flows: [
    { from: "s1", to: "s2", label: "…", kind: "data" },
    // …
  ],
};
```

- **Step kinds**: `setup | request | response | decision | error | output`.
- **Edge kinds**: `data` (solid accent) | `control` (dashed neutral) | `error` (red).
- `lines` ranges reference `main.go`. Indent `code` with tabs — the page
  expands them for display, matching the site's other code blocks.
- Step/edge colors live in the token block at the top of `../index.html`
  (`--k-*`, `--e-*`).

## Loading model

The page lazy-loads: opening the Step-through tab injects
`<script src="data/<leaf>.js">` on demand and caches the result. A missing or
broken file shows an inline error card in that tab only — the Diagram tab and
source panel are unaffected. Deep links use `#/examples/<catalog>/<leaf>/walkthrough`.
